# Lab 1 - Java Arrays ![Java](https://img.shields.io/badge/Language-Java-red)

A simple Java project demonstrating **basic array operations** using an **object-oriented approach**.

**Features:**  
- Insert, display, search, and delete elements  
- Display a part of the array  
- Insert elements in sorted order (`insertSorted`)  
- Rotate the array (`rotate`)  

**Example Run:**  
```
Enter 5 numbers: 10 20 30 40 50
The set contains: 10 20 30 40 50
Search for key: 30 → Found
Delete key: 20 → Deleted
After insertSorted(25): 10 25 30 40 50
After rotate(2): 40 50 10 25 30
```

**How to Run:**  
Compile and run `Lab_01_EX.java` with `ArrayClass.java`.
